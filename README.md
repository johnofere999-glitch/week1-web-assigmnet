My Budget Tracker

Project Description

My Budget Tracker is a simple web page that helps users record and view their expenses. The project was built using HTML and CSS as part of the Week 2 technical coding challenge.

What I Built

The project includes:

* An expense form for entering expense details.
* A category dropdown with Food, Transport, Rent, Entertainment, and Other.
* An expense table showing sample expenses.
* A budgeting tips video using an iframe.
* A budget tracker icon using an image.
* A collapsible "How to use this tracker" section.
* CSS styling for the form, table, buttons, and page sections.
* Advanced CSS selectors and interactive hover and focus effects.
